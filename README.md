## Tuzilishi

- `sim/` — simulyatsiyalar (oddiy HTML + JavaScript, tashqi kutubxonalarsiz, telefonda ishlaydi).
- `qr/` — QR-kodlar olib boradigan yoʻnaltiruvchi sahifalar. Material manzili oʻzgarsa, faqat shu yerdagi havola almashtiriladi.
- `qr-kodlar/` — kitobga qoʻyish uchun tayyor QR-kod rasmlari.
- `assets/` — umumiy uslub va yordamchi skriptlar.
